# One Line Labyrinth

A one-line path puzzle built with Flutter for iOS, Android, and web.

Draw a single line from the filled start knot to the ring, visiting every knot
exactly once and only moving along the drawn links.

## Features

- Knots sit on a jittered grid (Easy 4x4, Normal 5x5, Hard 6x6); the grid grows
  every two levels up to 5x5 / 6x6 / 7x7.
- Every puzzle has a hidden Hamiltonian solution built from grid moves, so links
  never cross. Harder modes add more decoy links (and a few diagonals on Hard)
  that lead into dead ends.
- Tap knots one by one or drag across them. Tap or drag back onto the previous
  knot to undo a step; the undo button resets the line, the shuffle button deals
  a new puzzle.
- A first-run "How to play" card (skippable; reopen with the ? button) explains the rules and is remembered via `tutorial_seen_v1`.
- Sound effects (step, undo, invalid tap, solved) with a sound on/off button next
  to the ? button; the choice is remembered via `sound_muted_v1` and CrazyGames
  muting is respected.
- Constellation look: knots are stars, the line is a glowing thread, drawn
  with `CustomPainter` over an animated night sky (no image assets).
  Visiting, backtracking, dead ends and solving each have their own effect.
- Stars per level: solve it, keep a clean line (no undo, reset or hint) and
  beat the par time (1.6 s per knot + 4 s). The hint button (or H) rewinds
  the line to the hidden solution and lights the next star.
- After a solve a result card shows the constellation name, stars, XP and
  unlocks (Enter = next level). A level map replays any unlocked level, and a
  constellation album keeps the line you drew on the first clear of levels
  1-12 of each difficulty.
- Sky level (XP) unlocks four cosmetic skies: Twilight, Aurora (Lv3),
  Nebula (Lv6) and Eclipse (Lv10).
- Keys: Backspace/Z undo, R reset, H hint, N new puzzle, M level map,
  Enter/Space next level, Esc closes menus.
- Progress is saved under `labyrinth_progress_v1`; the older
  `best_level_<difficulty>` keys are still read and written, so no best level
  is lost.
- After finishing a level you can optionally register your time on the shared
  leaderboard.
- Layout adapts to phone portrait and desktop landscape screens.

Puzzle generation lives in `lib/puzzle_generator.dart` (widget-free, seedable
with `Random`) and is covered by `test/puzzle_generator_test.dart`.

## Run Locally

```sh
flutter pub get
flutter run -d chrome
flutter test
```

## Local Web Build

```sh
flutter build web --release --base-href /OneLineLabyrinth/
```

GitHub Pages deploys from `.github/workflows/deploy-pages.yml`.

## CrazyGames Build

`tool/build_crazygames.sh` builds `build/one-line-labyrinth-crazygames.zip` for the CrazyGames portal (SDK events, no hub link, no leaderboard). See `docs/crazygames.md`.

## GamePix Web Build

`tool/build_gamepix.sh` builds `build/gamepix/` and the upload zip `build/one-line-labyrinth-gamepix.zip` (SDK-free; no hub link, leaderboard or ads). See `docs/gamepix.md`. Roboto is bundled in `assets/fonts/` (see `assets/fonts/Roboto_LICENSE.txt`) so web builds make no font requests.

## Sounds

Sound effects live in `assets/audio/` and the ambient music loop
(16 kHz mono, about 750 KB) in `assets/music/`; both are generated by
`tool/generate_sounds.py` (Python 3 standard library only, deterministic; no
third-party audio). Regenerate them with:

```sh
python3 tool/generate_sounds.py
```
